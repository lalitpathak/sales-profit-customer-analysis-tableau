# Dashboard Design Notes

## Objective

The primary goal of this dashboard was to create a modern and visually intuitive business intelligence solution capable of presenting key sales and profitability insights in a concise and interactive format.

The dashboard was designed to balance:
- analytical clarity
- executive readability
- modern UI aesthetics
- interactive exploration

---

# Design Approach

## 1. KPI-First Layout

The dashboard begins with high-level KPI cards to immediately communicate the overall business performance.

Displayed KPIs:
- Total Sales
- Total Profit
- Total Orders
- Total Customers

This allows users to quickly understand business health before exploring detailed visualizations.

---

## 2. Visual Hierarchy

The dashboard follows a structured hierarchy:

1. Executive KPIs
2. Regional performance analysis
3. Category and segment analysis
4. Customer and manager insights

This layout improves readability and reduces cognitive overload.

---

# Color Palette & Styling

## Background

A textured dark-blue background was used to:
- improve contrast
- enhance dashboard aesthetics
- create a modern analytical interface

## Accent Colors

Soft pastel tones were selected for charts and KPI cards to:
- maintain readability
- avoid aggressive visual contrast
- support a clean dashboard experience

---

# Dashboard Components

## KPI Cards

Custom KPI cards were designed using:
- floating containers
- custom background elements
- minimal typography
- trend indicators

## Map Visualization

A geographical map was included to analyze sales distribution across U.S. states and identify high-performing regions.

## Bar Charts

Horizontal and vertical bar charts were used for:
- manager performance analysis
- category comparison
- customer contribution analysis

These chart types provide fast comparative analysis.

---

# User Experience Considerations

The dashboard was designed with:
- clear spacing
- consistent alignment
- minimal clutter
- intuitive navigation

Special attention was given to maintaining readability across all visualizations.
