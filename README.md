**📊 Tableau Sales Performance Dashboard**

An interactive Tableau dashboard built using the dataset to analyze business performance across sales, profit, customers, categories, regions, and managers. The dashboard focuses on creating a modern analytical experience using KPI cards, geographical analysis, category insights, customer analysis, and manager-level performance tracking.

**🚀 Project Overview**

This dashboard was developed to provide a consolidated view of retail business performance and help answer key business questions such as:

Which product categories generate the highest sales?
Which states contribute the most revenue?
Which managers drive the strongest performance?
How do customer segments differ in purchasing behavior?
Which sub-categories are underperforming?
What is the relationship between sales and profit?

The project combines data visualization, dashboard design principles, and business storytelling to create an intuitive decision-making interface.
